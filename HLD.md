# High-Level Design (HLD)

## 1. Overview
This project is a personal portfolio website for Lagan. It presents the developer’s identity, learning journey, interests, and contact information using a simple one-page design.

## 2. Goals
- Showcase the portfolio in a clean and visually appealing format
- Keep the website easy to maintain and lightweight
- Make the layout responsive for desktop and mobile devices
- Highlight the student developer profile and personal brand

## 3. Users
- Recruiters and potential collaborators
- Visitors reviewing the portfolio
- Friends and peers

## 4. High-Level Architecture
The site follows a static frontend architecture:

- HTML defines content structure
- CSS controls visuals and layout
- JavaScript adds small dynamic behavior, such as updating the current year

## 5. Main Page Sections
1. Header with brand and navigation
2. Hero section with introduction and call-to-action buttons
3. About section
4. Projects / ideas section
5. Interests section
6. Contact section
7. Footer

## 6. Design Principles
- Simple and modern layout
- Soft pink/pastel palette to match the personal aesthetic
- Strong readability and alignment
- Responsive behavior on smaller screens
- Semantic structure for accessibility

## 7. Non-Functional Requirements
- Fast load time
- No heavy frameworks or dependencies
- Easy content updates in HTML/CSS
- Works across modern browsers

## 8. Future Extensibility
The project can be expanded with:
- Social media links
- Resume download
- Project images and live demos
- Additional pages or animations
